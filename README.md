#  Диет-бот "VitaBalance"

Telegram-бот для персонализированного расчёта КБЖУ, генерации меню на день/неделю, дневника питания и воды, базы рецептов и AI-коуча по питанию.

##  Функции

- Расчёт суточной нормы калорий, белков, жиров, углеводов (формула Миффлина – Сан-Жеора).
- Генерация рациона на день или неделю с учётом:
  - физических параметров (возраст, вес, рост, пол, активность, цель);
  - типа диеты (сбалансированная, низкоуглеводная, кето, вегетарианская, средиземноморская);
  - уровня бюджета (низкий, средний, высокий);
  - исключений/аллергий (глютен, лактоза, орехи, курица, рыба, морепродукты, свинина, говядина, яйца, соя).
- Дневник еды и воды (добавление продуктов по названию, автоматический подсчёт КБЖУ).
- База рецептов (40+ рецептов, 40+ продуктов) с поиском, фильтрацией по категориям и возможностью добавления своих рецептов.
- Сохранение созданных рационов, просмотр истории, установка активного плана.
- Экспорт недельного рациона в PDF.
- AI-коуч "Vita" (интеграция с локальной LLM через LM Studio) с эмпатичной поддержкой и навигацией по меню.
- Управление профилем (изменение параметров, диеты, ограничений, удаление профиля).

## Установка и запуск

### Требования

- Node.js (версия 18 или выше)
- Telegram Bot Token (получить у [@BotFather](https://t.me/BotFather))
- (опционально) LM Studio с загруженной моделью (например, Qwen 2.5) для работы AI-коуча

### Шаги

1. **Клонируйте репозиторий** (или просто скопируйте файлы проекта в отдельную папку):
   ```bash
   git clone https://github.com/ваш-аккаунт/vita-balance-bot.git
   cd vita-balance-bot

2. Установите зависимости
npm install

3. Создайте файл .env в корне проекта и добавьте ваш токен:
BOT_TOKEN=ваш_токен_от_BotFather

4. Заполните базу данных начальными продуктами и рецептами (выполните один раз):
node seedData.js

5. Запустите бота:
node bot.js

6. Настройка AI-коуча (опционально):
Скачайте и установите LM Studio.
Загрузите модель (например, qwen2.5-14b-instruct).
Запустите локальный сервер на http://127.0.0.1:1234 (вкладка "Local Inference Server").
Убедитесь, что в qwen.js указан корректный URL.
Без AI-коуча бот продолжает работать, просто команды "Vita AI" будут выдавать ошибку.

Команды бота 
/start	Начать диалог, создать или сбросить профиль
/menu	Показать главное меню
/recalc	Пересчитать КБЖУ на основе текущего веса

Примеры использования
Новый пользователь: /start → вводит имя, пол, возраст, рост, вес, целевой вес, активность → выбирает цель → получает рекомендацию по диете → видит свою норму КБЖУ.

Создать рацион на неделю: Главное меню → Питание → Рацион на неделю → Создать → выбрать бюджет → бот генерирует 7 дней с завтраком, обедом, ужином и перекусом.

Добавить еду в дневник: Питание → Дневник еды → Добавить приём пищи → ввести "гречка 150" → бот найдёт продукт и запишет.

Экспорт в PDF: Питание → Рацион на неделю → Посмотреть рацион → выбрать нужный → нажать "Скачать рацион PDF".

Изменить диету: Профиль → Изменить диету → выбрать новый тип.
